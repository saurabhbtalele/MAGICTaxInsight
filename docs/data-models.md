# Data Models

This page explains the shape and structure of the intermediate Python models passed through memory, as well as the final JSON output generated by the application.

## Internal Python Models

These dataclasses operate exclusively in memory (inside `models/document.py`):

### `ParsedDocument`

The wrapper root after Step 1 of the pipeline runs. Contains raw page texts and scanning/OCR metadata.

```python
@dataclass
class ParsedPage:
    page_number: int
    raw_text: str

@dataclass
class ParsedDocument:
    filename: str
    total_pages: int
    pages: list[ParsedPage]
    metadata: dict[str, Any]          # Includes "source_path", scan/ocr metadata
    extracted_forms: list[ExtractedForm]
```

### `DetectedForm`

Generated by Step 2. Contains location and confidence scores but NO extracted form values yet.

```python
@dataclass
class DetectedForm:
    form_id: str
    display_name: str
    page_numbers: list[int]
    confidence: float
```

### `ExtractedForm`

Generated by Step 3. Represents a fully populated tax form chunk in memory.

```python
@dataclass
class ExtractedForm:
    form_id: str
    display_name: str
    page_numbers: list[int]
    confidence: float
    fields: dict[str, Any]
    tax_year: str | None = None          # "2024", "2023" — extracted from form header
    instance_index: int = 0              # For multi-instance forms (Sched C #1, #2...)
    extraction_tier_used: str | None = None  # Audit: which strategy was used
```

## The JSON API Contract

When the script runs completely, the script iterates through all `ExtractedForm` arrays and outputs the following envelope:

### Envelope Example

```json
{
  "filename": "tax_package_2024.pdf",
  "total_pages": 4,
  "processed_at": "2026-03-04T14:30:00Z",
  "extraction_tier": "tesseract_ocr",
  "forms": [
    {
      "form_id": "W-2",
      "display_name": "Form W-2 (Wage and Tax Statement)",
      "tax_year": "2024",
      "instance_index": 0,
      "page_numbers": [1, 2],
      "confidence": 0.95,
      "extraction_tier_used": "pdfplumber",
      "fields": {
        "employee_ssn": "XXX-XX-6789",
        "employer_name": "ACME CORPORATION",
        "wages_tips_other_compensation_box_1": 82500.0
      }
    }
  ]
}
```

This output is then handed over to the external .NET consuming layers (acting as the API Gateway/Workflow router) to process against business calculation engines dynamically.
